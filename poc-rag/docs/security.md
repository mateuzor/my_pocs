# Security basics

Passwords must have at least 14 characters. Use the company password manager and never reuse a password.

Multi-factor authentication is mandatory for email, the VPN, and the code repository.

If you lose a laptop or phone, tell the security team in the first hour. Write to security@acmelabs.example or call the security hotline.

Customer data can only be used in the production environment. Never copy customer data to your laptop.
