# Live demo script (about 2:45)

Prep (before the talk)
1. `cd poc-kubb && npm run demo:reset`
2. In the VS Code terminal: `nvm use 22 && node -v` (must be v22.22+).
3. VS Code: zoom in (Cmd +, 3 or 4 times), hide the minimap, close other tabs.
4. Open these tabs: `petStore.yaml`, `kubb.config.ts`, `src/index.ts`. Keep the explorer open.
5. Backup: slides 7 and 8 are hidden in the deck (config and spec diff). Record a screen video of this flow.

Flow
1. (0:20) Show `petStore.yaml`: "one endpoint, one Pet schema". Then `kubb.config.ts`: "input, output, three plugins".
2. (0:15) Show `src/index.ts`: red squiggles, because `src/gen` does not exist yet.
3. (0:30) Terminal: `npm run generate`. `src/gen` appears (9 files, ~200 ms). Squiggles disappear.
4. (0:25) Open `models/Pet.ts` and `clients/getPetById.ts`: "Generated by Kubb, do not edit manually".
5. (0:20) In `index.ts`, change `pet.name` to `pet.tag`. Red squiggle: the spec has no `tag` yet.
6. (0:25) In `petStore.yaml`, add under `name`: `tag:` / `type: string`. Run `npm run generate` again. Squiggle disappears; `Pet.ts` has `tag?: string`.
7. (0:10) Optional: `npx tsc -p .` in the terminal to show a clean typecheck.

If it breaks: switch to the hidden slides 7-8 (press the slide number + Enter in slideshow mode), or play the video.
