# Live demo script (about 2 minutes, no editing)

Prep (before the talk)
1. `cd poc-kubb && npm run demo:reset`
2. In the VS Code terminal: `nvm use 22 && node -v` (must be v22.22+).
3. VS Code: zoom in (Cmd +, 3 or 4 times), hide the minimap, close other tabs.
4. Open these tabs: `petStore.yaml`, `kubb.config.ts`, `src/index.ts`. Keep the explorer open.
5. Backup: slides 7 and 8 are hidden in the deck (config and spec diff). Record a screen video of this flow.

Flow
1. (0:25) Show `petStore.yaml`: "this is our API documentation, in OpenAPI. One endpoint, one Pet schema."
2. (0:25) Show `kubb.config.ts`: "one simple file: the spec, the output folder, three plugins. Very configurable."
3. (0:20) Show `src/index.ts`: red, because the client and the Pet type do not exist yet.
4. (0:50) Terminal: `npm run generate`. 9 files in ~200 ms, the red is gone. Open `models/`, `clients/`, `zod/`. Point at "Generated by Kubb, do not edit manually".

If it breaks: switch to the hidden slides 7-8 (press the slide number + Enter in slideshow mode), or play the video.

Reset between rehearsals: `npm run demo:reset` (full walkthrough also in `../README.md`)
