# poc-node-backend

Estudos de backend com Node.js — seguindo a estrutura de um curso do zero.

## Progressão

1. **Fundamentos** — HTTP nativo, módulos do core (fs, path, streams)
2. **Express** — REST CRUD, middlewares, validação, tratamento de erros
3. **Estrutura + Persistência** — MVC (routes → controllers → services) + SQLite

## Rodar

```bash
npm install
npm run dev
```
